## 🇧🇷 Sobre este repositório (Português)

Fala, pessoal! 👋 

Este repositório é o meu caderno de anotações e laboratório de testes das aulas de **"User Experience Developer: Front-End Interfaces"** que tive durante minha formação na FIAP. 

Como o meu foco principal é Desenvolvimento de Jogos (C# e Unity), decidi mergulhar de cabeça nesse módulo de Front-End para ganhar mais versatilidade. Entender como a web funciona é essencial não só para criar sites para os meus próprios jogos, mas também para entender as lógicas de UI/UX (Interface e Experiência do Usuário) que eu aplico dentro das *engines*.

### 📂 O que tem aqui dentro?
O repositório está organizado cronologicamente (da Aula 1 até a 9), acompanhando a minha curva de aprendizado:
* **Estrutura Base:** Muito HTML para construir o esqueleto das páginas.
* **Estilização:** CSS puro para entender as regras de design e responsividade.
* **Frameworks:** Introdução ao Bootstrap (Aula 7) para criar interfaces rápidas e modernas.
* **Dinamismo:** Os primeiros passos com JavaScript para dar vida aos elementos da tela.

## 🇺🇸 About this repository (English)

Hey everyone! 👋

This repository is my code journal and testing ground for the **"User Experience Developer: Front-End Interfaces"** classes I took at FIAP. 

Since my main background is in Game Development (C# and Unity), I dove into this Front-End module to become a more versatile developer. Understanding web technologies is crucial not only for building landing pages for my games but also for applying solid UI/UX logic directly inside game engines.

### 📂 What's inside?
The repository is organized chronologically (from Class 1 to 9), following my learning curve:
* **Core Structure:** Solid HTML to build the skeleton of the web pages.
* **Styling:** Pure CSS to understand design rules and responsive layouts.
* **Frameworks:** Introduction to Bootstrap (Class 7) for fast and modern interfaces.
* **Interactivity:** Early steps with JavaScript to bring the screens to life.
